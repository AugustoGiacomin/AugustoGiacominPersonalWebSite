# AGIACOMIN — Site

## Deploy no GitHub Pages

1. Acesse github.com e crie uma conta (se não tiver)
2. Crie um repositório público chamado `agiacomin`
3. Faça upload dos arquivos `index.html` e `style.css`
4. Vá em **Settings → Pages → Branch: main → Save**
5. Após ~1 minuto, seu site estará em: `https://SEU_USUARIO.github.io/agiacomin`

## Alternativa rápida — Netlify Drop

1. Acesse netlify.com/drop
2. Arraste a pasta `agiacomin-site` para a área indicada
3. Pronto — URL instantânea com HTTPS

## Arquivos

- `index.html` — estrutura e conteúdo
- `style.css` — design system completo
